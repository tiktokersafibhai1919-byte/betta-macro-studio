# 🐠 Betta Macro Studio

**Studio by Mr Safi** — A minimalist, camera-viewfinder AI photography studio engineered to generate ultra-realistic 8K macro images of exotic Betta fish varieties.

🔗 **Live Studio:** [Launch Betta Macro Studio](https://tiktokersafibhai1919-byte.github.io/betta-macro-studio/)

## ✨ Features
* **Leica / Apple Camera Viewfinder UI:** Rule-of-thirds composition grid, live recording telemetry (`100mm Macro • f/2.8 • 8K RAW`), and clean matte-silver studio layout.
* **Betta Variety & Morph Selector:** Supports Halfmoon, Crowntail, Plakat, Galaxy Koi, Dumbo Ear, and Alien Metallic morphs with custom studio lighting.
* **1-Click HD Save & Motion Prompt:** Direct `.jpg` download to your device plus one-tap video animation prompt copying for slow-motion Reels/Shorts.

## 📂 Project Files
* `index.html` — Camera viewfinder interface & optical controls
* `style.css` — Minimalist white & matte-silver studio theme
* `script.js` — 8K macro prompt builder, image loader & HD downloader
